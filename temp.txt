==========================================================
1. PRINCIPE FONDAMENTAL
==========================================================

La délibération est semi-automatique.

Le système calcule déjà les situations académiques depuis :

- résultats S1 ;
- résultats S2 ;
- rattrapages déjà publiés ;
- crédits ;
- règles académiques ;
- seuils ;
- dettes ;
- règles de passage.

Ces calculs constituent la PROPOSITION SYSTÈME.

Le DE / jury intervient principalement sur les CAS À EXAMINER.

Il ne faut PAS transformer la délibération en saisie manuelle
de 20, 100 ou 500 décisions étudiantes.

==========================================================
2. CAS ORDINAIRES
==========================================================

Exemple visible actuellement :

Moussa Dembélé

S1 validé
S2 validé

Proposition système :
Promu

État :
Ordinaire

Ce dossier ne doit pas obligatoirement demander :

Examiner
→ sélectionner Promu
→ justification
→ enregistrer

La proposition système est déjà déterministe.

Pour un cas ordinaire sans anomalie ni intervention du jury,
la décision effective peut être confirmée automatiquement lors
de la clôture de séance.

IMPORTANT :

ne pas créer silencieusement une décision officielle dès l’ouverture
de la page.

Avant clôture, elle reste une proposition système.

À la clôture :

proposition système ordinaire
→ décision jury effective confirmée automatiquement.

Tracer cette confirmation comme issue de la clôture collective.

==========================================================
3. CAS À EXAMINER
==========================================================

Les cas ambigus restent obligatoirement traités.

Dans l’exemple actuel :

20 étudiants
14 à examiner

Le travail humain doit porter principalement sur ces 14 dossiers.

Chaque cas à examiner doit avoir une décision explicite avant
clôture.

Exemples :

- passage avec dette ;
- repêchage ;
- redoublement ;
- situation proche du seuil ;
- décision dérogatoire ;
- anomalie académique ;
- autre situation réellement identifiée par le moteur.

==========================================================
4. PROGRESSION RÉELLE
==========================================================

Aujourd’hui on voit :

20 étudiants
0 traités
14 à examiner

Ce compteur peut être trompeur.

Distinguer clairement :

TOTAL
20

CAS ORDINAIRES
6

CAS À EXAMINER
14

CAS EXCEPTIONNELS TRAITÉS
X / 14

Ainsi le DE comprend immédiatement que les 6 dossiers ordinaires
n’exigent pas 6 interventions manuelles.

==========================================================
7. BOUTON PRINCIPAL : CLÔTURER LA DÉLIBÉRATION
==========================================================

Lorsque TOUS les cas nécessitant une intervention humaine sont
traités et qu’aucune anomalie bloquante ne subsiste :

afficher clairement un bouton principal :

[ VALIDER ET CLÔTURER LA DÉLIBÉRATION ]

C’est une action du Directeur des Études.

Ce bouton ne publie PAS encore les résultats aux étudiants.

Ce bouton ne déclenche PAS encore la réinscription.

Ce bouton ne contourne PAS le DG.

Il signifie :

"Le jury / DE confirme que le travail de délibération de cette
classe est terminé."

==========================================================
9. AU MOMENT DE LA CLÔTURE
==========================================================

Dans une transaction atomique :

1. vérifier qu’aucun cas obligatoire n’est non traité ;

2. vérifier qu’aucune anomalie bloquante ne subsiste ;

3. pour les cas ordinaires sans décision jury explicite :
   confirmer la proposition système comme décision effective ;

4. pour les cas examinés :
   conserver la décision jury enregistrée ;

5. figer le snapshot annuel de délibération ;

6. enregistrer :
   - DE ayant clôturé ;
   - date/heure ;
   - annexe ;
   - année ;
   - classe ;
   - règles utilisées ;
   - éventuelle règle de repêchage ;
   - décisions finales de séance ;

7. rendre la séance clôturée.

AUCUNE NOTE n’est modifiée.

==========================================================
11. IMPORTANT — CLÔTURE ≠ TRANSMISSION
==========================================================

Ce sont DEUX actions distinctes.

ÉTAPE A

DE
→ Valider et clôturer la délibération

ÉTAPE B

DE
→ Soumettre au DG pour approbation

Pourquoi ?

Parce que le DE peut vouloir :

- clôturer ;
- relire le PDF ;
- vérifier la synthèse ;
- imprimer éventuellement ;
- puis transmettre.
