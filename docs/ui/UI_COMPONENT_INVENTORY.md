# Inventaire des composants UI

> Phase 1.5 : les composants `ui_core.*` sont désormais rangés par domaines
> techniques. Les chemins ont été actualisés; les noms publics restent inchangés.

> Phase 1.75 : six fondations génériques ont été ajoutées après comparaison avec
> les composants historiques : `ui_core.tabs`, `ui_core.dropdown_menu`,
> `ui_core.progress_bar`, `ui_core.timeline`, `ui_core.chart_panel` et
> `ui_core.form_field`. Les composants historiques restent enregistrés.

## Décisions de réutilisation Phase 1.75

| Besoin | Source examinée | Décision |
|---|---|---|
| tabs | `dashboard.tabs`, `academic_tabs` | nouveau contrat générique `ui_core.tabs`; historiques conservés pour leurs contrats HTMX |
| menu | `interactive.dropdown` | présentation simplifiée dans `ui_core.dropdown_menu`; composant historique conservé |
| progression | `dashboard.progress_bar` | API sémantique bornée dans `ui_core.progress_bar` |
| timeline | `dashboard.timeline`, `academic_timeline` | fondation sans sémantique académique dans `ui_core.timeline` |
| graphiques | `dashboard.chart_card` | `ui_core.chart_panel` avec API JS centralisée et destruction idempotente |
| champs | composants `forms.*` | façade de catalogue `ui_core.form_field`; les contrôles historiques restent la base des formulaires métier |

Généré le 25 juillet 2026 à partir du dépôt. La recherche couvre les décorateurs, templates, Python, JavaScript, tests, imports explicites, includes et usages HTMX. Une absence de référence statique ne vaut jamais autorisation de suppression.

## Méthode

- Source réelle : UiConfig.ready() importe ui.components.
- ui/components/__init__.py importe les familles enregistrées.
- Usages approx. = fichiers distincts contenant le nom public, hors définition.
- Les composants métier sont conservés et composeront UI Core.
- ui_core.* coexiste avec les composants historiques.
