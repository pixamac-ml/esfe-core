SPRINT 8 — DASHBOARD DIRECTEUR DES ETUDES MODULE : SYNTHESE DE SUIVI
PEDAGOGIQUE Projet : ESFE Core Destinataire : Codex

OBJECTIF

Finaliser le dashboard du Directeur des Études en lui donnant une vue de
pilotage du suivi pédagogique.

IMPORTANT

Le Directeur des Études ne saisit aucun cahier de texte. Le Directeur
des Études ne modifie pas les séances. Le Directeur des Études ne
calcule pas les notes.

Le dashboard est uniquement un tableau de bord de contrôle.

MISSION

Créer ou consolider :

-   academics/services/director_monitoring_service.py
-   academics/selectors/director_monitoring_selectors.py

Réutiliser les services déjà développés :

-   academic_readiness_service
-   timetable_management_service
-   teacher_assignment_service
-   calendar_service

Aucune duplication de logique métier.

FONCTIONNALITES

Afficher par classe, formation et semestre :

-   état du calendrier académique
-   état des programmes UE/EC
-   état des affectations enseignants
-   état des emplois du temps
-   progression des cours (lecture uniquement)
-   cours non réalisés
-   cours reportés
-   enseignants absents
-   volumes horaires réalisés / restants
-   examens planifiés
-   notes importées (lecture uniquement)
-   résultats validés
-   bulletins publiés

TABLEAU DE BORD

Créer une synthèse avec :

-   indicateurs globaux
-   alertes bloquantes
-   anomalies pédagogiques
-   actions prioritaires

Chaque indicateur doit retourner :

-   statut (OK, Attention, Bloqué)
-   couleur
-   message
-   action recommandée

PERMISSIONS

-   Directeur des Études : son annexe.
-   DG / Super Admin : accès global.

TESTS

Créer des tests couvrant :

-   affichage des indicateurs
-   alertes
-   permissions
-   lecture seule
-   cohérence des synthèses

CONTRAINTES

Ne pas modifier : - moteur des notes - import Excel - dashboard
Informaticien - dashboard Surveillant Général

LIVRABLE

1.  Résumé.
2.  Fichiers créés.
3.  Fichiers modifiés.
4.  Tests.
5.  Commandes de test.
6.  Préparation de la refonte finale du dashboard Directeur des Études.

FIN DU SPRINT 8
