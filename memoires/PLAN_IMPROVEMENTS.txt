1. VALEUR AJOUTÉE PAR FONCTIONNALITÉ
================================================================================

FONCTIONNALITÉ              | VALEUR AJOUTÉE
----------------------------|------------------------------------------------------
Zoom visionneur             | Les étudiants lisent confortablement sur mobile/
                            | tablette. Sans ça, ils quittent le site.
                            |
Thumbnails pages            | Navigation rapide dans le mémoire. Utile pour
                            | trouver une section précise sans tout lire.
                            |
Favoris / Signets           | Un étudiant revient plus souvent. Il stocke ses
                            | mémoires et recommande le site.
                            |
Export citations            | Les chercheurs référencent tes mémoires dans
(BibTeX, APA, MLA)         | leurs travaux → plus de visibilité pour ESFE.
                            |
Partage social              | Chaque partage = publicité gratuite. Les mémoires
(WhatsApp, Facebook, etc.)  | circulent sur WhatsApp/Facebook.
                            |
Statistiques personnelles   | Fidélisation. L'étudiant voit son historique
                            | et reste engagé.
                            |
Barre de progression        | Le lecteur sait où il en est. Réduit l'abandon
                            | en cours de lecture.

2. CLASSEMENT PAR IMPACT
================================================================================

PRIORITÉ 1 — Coeur de l'expérience (Impact fort)
-------------------------------------------------
  [ ] Visionneur amélioré :
      - Zoom avant/arrière (molette + boutons)
      - Thumbnails sidebar (aperçu de toutes les pages)
      - Barre de progression
      - Navigation clavier (flèches, Espace, Esc)
      - Plein écran
      - Saut de page par input numérique

  Pourquoi : C'est ce que l'utilisateur passe 90% de son temps à faire.
             Un bon visionneur = un utilisateur satisfait = retour.

PRIORITÉ 2 — Engagement & Fidélisation (Impact moyen)
-----------------------------------------------------
  [ ] Mémoires similaires :
      - Section sous le visionneur avec 4 mémoires proches
      - Sélection par filière → mots-clés → année → encadreur
      - Cartes avec titre, filière, année, vues, badge niveau
      - Exclure le mémoire consulté des résultats

  [ ] Favoris / Signets :
      - Bouton "Ajouter aux favoris" sur chaque mémoire
      - Page "Mes favoris" accessible depuis le profil
      - Compteur de favoris

  [ ] Statistiques personnelles :
      - Nombre de mémoires consultés
      - Historique de lecture
      - Temps passé (optionnel)

  Pourquoi : Fait revenir l'utilisateur. Crée une habitude.

PRIORITÉ 3 — Visibilité & Crédibilité (Impact indirect)
-------------------------------------------------------
  [ ] Export de citations :
      - Bouton "Citer ce mémoire"
      - Formats : BibTeX, APA, MLA, Vancouver
      - Copier en un clic

  [ ] Partage social :
      - Boutons : WhatsApp, Facebook, Lien copié
      - QR Code automatique
      - Message pré-rempli pour WhatsApp

  Pourquoi : Attire du nouveau trafic sans effort marketing.

# 4. COMPORTEMENT DU VISIONNEUR

Le visionneur doit respecter les règles suivantes.

## Chargement

* afficher un état de chargement pendant l’ouverture du PDF ;
* afficher un message clair en cas d’échec ;
* ne pas laisser une zone vide sans explication ;
* ne pas bloquer toute la page pendant le chargement ;
* empêcher les erreurs JavaScript silencieuses.

## Navigation

* empêcher une navigation vers une page inférieure à 1 ;
* empêcher une navigation au-delà du nombre total de pages ;
* synchroniser le champ de page, la page affichée et la miniature active ;
* désactiver le bouton précédent sur la première page ;
* désactiver le bouton suivant sur la dernière page.

## Zoom

Prévoir des niveaux de zoom raisonnables.

Exemple acceptable :

* minimum : 50 % ;
* maximum : 250 % ;
* incrément : 10 % ou 25 % ;
* valeur initiale adaptée à la largeur disponible.

Le zoom ne doit pas rendre l’interface inutilisable sur mobile.

## Miniatures

* charger les miniatures progressivement si le document contient beaucoup de pages ;
* éviter de rendre toutes les pages en haute résolution dans la barre latérale ;
* sur mobile, permettre de masquer ou afficher la barre des miniatures ;
* mettre clairement en évidence la page active.

## Progression

La progression peut être calculée ainsi :

`page actuelle / nombre total de pages × 100`

Elle doit être mise à jour à chaque changement de page.

* si ce champ est correctement intégré dans les formulaires ;
* s’il apparaît dans l’administration Django standard ;
* s’il apparaît dans l’application ou le tableau de bord Super Admin ;
* si l’image est enregistrée correctement dans le stockage média ;

* si une ancienne implémentation existe mais n’est plus utilisée ;
* si une migration liée à ce champ existe déjà ;
* si les templates utilisent un mauvais nom de champ ou une mauvaise URL d’image.

Ne crée pas immédiatement un nouveau champ avant d’avoir vérifié qu’un champ équivalent n’existe pas déjà.

Il faut éviter d’avoir deux champs différents comme :

```python

cover
thumbnail
cover_image
featured_image
```

pour une même fonction.

Si un champ existe déjà, corrige son intégration au lieu d’en créer un second.

## 6. Image de remplacement

Lorsqu’un mémoire ne possède pas d’image, afficher une image de remplacement professionnelle.

Cette image par défaut peut être :

* une couverture générique de mémoire ;
* une illustration institutionnelle sobre ;
* un visuel représentant un document académique ;
* un placeholder cohérent avec la charte graphique ESFE.

Ne pas afficher :

* une image cassée ;
* une zone vide ;
* le texte brut du chemin du fichier ;
* une image externe non contrôlée.

La logique du template doit vérifier l’existence de l’image avant d’appeler son URL.

Exemple indicatif :

```django
{% if memoire.cover_image %}
    <img src="{{ memoire.cover_image.url }}" alt="{{ memoire.title }}">
{% else %}
    <img src="{% static 'images/memoires/default-cover.webp' %}"
         alt="Couverture par défaut du mémoire">
{% endif %}
```

Adapte les noms aux modèles et aux fichiers réellement présents.
