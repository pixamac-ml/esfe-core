WORKFLOW DE FORMATION — SALAIRES ET HONORAIRES

OBJECTIF
========
La gestionnaire doit distinguer deux circuits financiers totalement séparés :

1. Les salaires du personnel non enseignant.
2. Les honoraires des enseignants.

Ils ne doivent jamais être mélangés dans les calculs, les paiements, la caisse
ou les documents.


1. SALAIRES DU PERSONNEL
=========================

Personnes concernées
--------------------
Seuls les membres du personnel non enseignant sont concernés : secrétaire,
informaticien, surveillant, gestionnaire, gardien, etc.

Le salaire dépend du poste et du salaire mensuel officiel renseigné dans le
profil de chaque employé.

Étape 1 — Préparation automatique
---------------------------------
Dès qu'un salaire mensuel officiel est renseigné dans le profil d'un membre du
personnel, le système prépare automatiquement une fiche de paie pour le mois.

Dans l'espace Salaires, la gestionnaire peut utiliser « Synchroniser les
fiches » uniquement si une fiche manque. Il ne s'agit pas de recréer les
salaires à la main.

Étape 2 — Vérification de la fiche
----------------------------------
La gestionnaire sélectionne le mois concerné, puis ouvre la fiche de l'employé
pour vérifier :

- le salaire de base ;
- les primes ;
- les retenues ;
- les avances éventuelles ;
- le montant net à payer.

Formule :

  Net = salaire de base + primes - retenues - avances

Tant que la fiche est en statut « À vérifier », elle reste un brouillon de
contrôle : elle ne doit pas encore être payée.

Étape 3 — Mise à disposition
-----------------------------
Lorsque la fiche est correcte, la gestionnaire la rend « Disponible à retirer ».
L'employé reçoit alors une notification indiquant que son salaire peut être
retiré selon la disponibilité de la caisse.

Étape 4 — Retrait / paiement effectif
--------------------------------------
Quand l'employé se présente, la gestionnaire saisit uniquement le montant
réellement remis.

- Si tout le net est remis : statut « Retiré ».
- Si une partie est remise : statut « Retrait partiel ».
- Si la caisse est insuffisante : le paiement est refusé ; aucune sortie de
  caisse ne doit être créée.

Chaque paiement validé doit automatiquement :

- mettre à jour le montant déjà payé et le reste à payer ;
- mettre à jour le statut de la fiche ;
- créer une sortie de caisse rattachée au salaire ;
- conserver la trace de l'opération ;
- permettre la consultation ou l'impression du bordereau de paie.

Étape 5 — Avance sur salaire
----------------------------
Une avance est un cas particulier. Elle peut être accordée avant que la fiche
ne soit rendue disponible. Elle sort immédiatement de la caisse puis est
déduite du net final dans la fiche de paie.

Étape 6 — Correction après paiement
-----------------------------------
Une fiche déjà payée, totalement ou partiellement, ne se corrige pas librement.
La gestionnaire doit :

1. indiquer le motif de la correction ;
2. confirmer la demande ;
3. obtenir et saisir le code OTP de validation DG/DGA.

La correction est alors auditée et traçable.


2. HONORAIRES DES ENSEIGNANTS
=============================

Personnes concernées
--------------------
Uniquement les enseignants.

Un honoraire ne dépend pas d'un salaire mensuel fixe. Il dépend des heures de
cours réalisées et validées ainsi que du tarif horaire officiel de l'enseignant.

Étape 1 — Conditions de calcul
------------------------------
Pour qu'un honoraire puisse être préparé, il faut :

- un enseignant rattaché à l'annexe ;
- un tarif horaire renseigné dans son profil ;
- des cours réalisés et validés dans le cahier de texte / suivi pédagogique.

Étape 2 — Préparation automatique
---------------------------------
Le système totalise les heures de cours validées pour le mois et prépare la
fiche d'honoraire. La gestionnaire peut utiliser « Synchroniser les fiches »
pour rattraper ou actualiser une fiche non finalisée.

Étape 3 — Vérification de l'honoraire
-------------------------------------
La gestionnaire vérifie :

- le tarif horaire ;
- le nombre d'heures validées ;
- les ajustements ;
- les retenues ;
- les avances éventuelles ;
- le net à payer.

Formule :

  Brut = heures validées × tarif horaire + ajustements
  Net = brut - retenues - avances

La fiche reste « À vérifier » tant que ce contrôle n'est pas terminé.

Étape 4 — Mise à disposition
-----------------------------
Lorsque le contrôle est fini, la gestionnaire rend l'honoraire « Disponible à
retirer ». L'enseignant reçoit une notification.

Étape 5 — Retrait / paiement effectif
--------------------------------------
Au retrait, la gestionnaire saisit le montant réellement remis à l'enseignant.

- Montant total : statut « Retiré ».
- Montant partiel : statut « Retrait partiel ».
- Caisse insuffisante : paiement bloqué, sans sortie de caisse.

Chaque retrait crée automatiquement une sortie de caisse de type « Honoraire »
et met à jour le bordereau de l'enseignant.

Étape 6 — Correction après paiement
-----------------------------------
Comme pour les salaires, toute correction d'un honoraire déjà payé exige :

1. un motif ;
2. une confirmation ;
3. une validation OTP DG/DGA ;
4. une trace d'audit.


RÈGLE À RETENIR POUR LA FORMATION
=================================

Salaire : personnel non enseignant, basé sur le salaire mensuel officiel.

Honoraire : enseignant, basé sur les heures de cours validées multipliées par
le tarif horaire officiel.

Dans les deux cas, la gestionnaire vérifie d'abord, rend disponible ensuite,
puis enregistre seulement le retrait réel. Le paiement diminue la caisse et
reste définitivement traçable.
